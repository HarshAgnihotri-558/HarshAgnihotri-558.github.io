# Harsh Agnihotri — Portfolio Website

A responsive portfolio website built with plain HTML, CSS, and JavaScript.

## Run locally
1. Extract the ZIP file.
2. Open `index.html` in your browser.

## Customize
- Edit the copy and sections in `index.html`.
- Adjust colors, layout, and responsive styles in `style.css`.
- In `script.js`, replace `your-email@example.com` with your real email address to enable the contact form's email draft behavior.
- Replace the three clearly labeled sample project concepts in the Work section with real projects when available.

## Notes
- No build tools or frameworks are required.
- Google Fonts are loaded online; the site falls back to local sans-serif fonts if unavailable.
- The contact form opens the visitor's email app. It does not send messages automatically or store them on a server.
